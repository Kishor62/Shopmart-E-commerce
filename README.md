# ShopMart – E-commerce Platform

Full-stack e-commerce app built with React (Frontend) and Node.js (Backend).

## Project Structure

ShopMart/
├── shopmat_Frontend/ # React + Vite + Tailwind + Redux
├── shopmart_Backend/ # Node.js / Express API
├── .gitignore
└── README.md

## Features

- Product listing & category filters
- Product details page
- Cart & Wishlist (Redux)
- Search products
- User auth (Login / Signup)
- Responsive modern UI

## Tech Stack

| Layer    | Technology                                     |
| -------- | ---------------------------------------------- |
| Frontend | React, Vite, Tailwind CSS, Redux, React Router |
| Backend  | Node.js, Express                               |
