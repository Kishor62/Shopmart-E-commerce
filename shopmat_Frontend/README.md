# ShopMart - React E-commerce

A complete beginner-friendly e-commerce frontend built with React, Tailwind CSS, Redux Toolkit, React Router and DummyJSON API.

## Features
- Product API integration
- Search
- Category filtering
- Sorting
- Product details
- Add to cart
- Quantity controls
- Wishlist
- LocalStorage persistence
- Checkout form
- Responsive Tailwind UI
- Loading and empty states

## Run

```bash
npm install
npm run dev
```

Open the URL shown by Vite, normally http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## API
This project uses DummyJSON:
https://dummyjson.com/products

The prices are converted approximately to INR for UI display.
